สร้างซอฟแวร์สำหรับอ่าค่าUPS จาก USB โดยใช้งานใน windows
-ซอฟแวร์ต้องทำงานเป็นลักษณะแบบ system tray ซึ่งจะต้องทำงานอยู่เบื้องหลังได้
-ซอฟแวร์จะเข้าUI ได้ผ่าน localhost:(พอร์ตที่ไม่ได้ใช้งานบ่อยๆ) เพื่อสั่งการเปิด/ปิดการทำงานของซอฟแวร์ และการตั้งค่าต่างๆ
-ใช้ภาษา python ในการเขียน และซอฟแวร์ต้องสามารถนำไปเผยแพร่ได้แบบ exe และเป็นตัวติดตั้ง
-เมื่อไฟฟ้าบ้านดับ ให้ระบบขึ้นแจ้งเตือนที่แถบแจ้งเตือนของ windows 
-และสามารถสั่งตั้งเวลาปิดเครื่องได้เมื่อไฟฟ้าดับ หรือแบตเตอร์รี่เหลือเท่าไหร่
-เมื่อไฟฟ้ากลับมา ให้ระบบขึ้นแจ้งเตือนที่แถบแจ้งเตือนของ windows
-ระบบต้องแสดงข้อมูลสถานะของUPS ใน UI เช่น สถานะไฟฟ้าบ้าน, ระดับแบตเตอร์รี่, เวลาที่เหลือ, สถานะการชาร์จ
-ระบบต้องแสดงรายละเอียดรุ่นของ UPS
