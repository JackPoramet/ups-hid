# คู่มือการใช้งาน `ups_module` สำหรับ Windows 🪟

โมดูล `ups_module` ถูกออกแบบมาให้สามารถทำงานบน Windows ได้อย่างสมบูรณ์แบบ (Plug & Play) โดยสามารถอ่านค่าตัวแปรทั้งหมด รวมถึง **Input Voltage (214-215V)** ซึ่งปกติแล้ว Windows มักจะบล็อกเอาไว้

## 🌟 ฟีเจอร์เด่นบน Windows
- **ไม่ต้องติดตั้ง WinpowerG2:** โมดูลมาพร้อมกับ Filter Driver (`libusb0.sys`) ในตัว
- **ไม่ต้องใช้ Zadig:** ไม่จำเป็นต้องสลับไดรเวอร์ให้วุ่นวาย
- **ไอคอนแบตเตอรี่ไม่หาย:** ระบบของ Windows จะยังคงมองเห็น UPS เป็นแบตเตอรี่ปกติ ทำให้คุณยังคงดู % แบตเตอรี่จากมุมขวาล่างของจอได้ตามปกติ

---

## 🚀 การเริ่มต้นใช้งาน (Plug & Play)

เมื่อคุณเรียกใช้งาน `UPSClient()` ครั้งแรกบนเครื่อง Windows เครื่องใหม่ สคริปต์จะทำการตรวจสอบว่าเครื่องของคุณมี Filter Driver หรือยัง

1. **ครั้งแรกที่รันสคริปต์:** 
   หากเครื่องยังไม่มีไดรเวอร์ ระบบจะเด้งหน้าจอ **User Account Control (UAC)** ขึ้นมาถามสิทธิ์ Administrator
2. **กดยืนยัน (Yes):**
   เพื่อให้ระบบทำการสอดไส้ Filter Driver แบบเงียบๆ (Silent Install) ซึ่งใช้เวลาเพียง 2-3 วินาที
3. **ใช้งานได้ทันที:**
   สคริปต์จะเริ่มดึงข้อมูลทั้งหมดออกมาได้ตามปกติ และจะไม่ถามสิทธิ์ UAC อีกในการรันครั้งต่อๆ ไป!

---

## 💻 ตัวอย่างโค้ดเบื้องต้น

```python
from ups_module import UPSClient

# ใช้ with statement เพื่อปิดการเชื่อมต่ออัตโนมัติเมื่อทำงานเสร็จ
with UPSClient() as client:
    print("สถานะ UPS:", client.get_status())
    print("แบตเตอรี่คงเหลือ:", client.get_var("battery.charge"), "%")
    print("แรงดันไฟเข้า:", client.get_var("input.voltage"), "V")
```

## 🛠️ โครงสร้างไฟล์ที่จำเป็นสำหรับ Windows
หากคุณต้องการก๊อปปี้โปรเจกต์นี้ไปรันที่เครื่องอื่น โปรดตรวจสอบให้แน่ใจว่าโฟลเดอร์ต่อไปนี้ถูกก๊อปปี้ไปด้วย:
```text
ups_module/
└── drivers/
    └── windows/
        ├── install-filter-win.exe   <-- ตัวติดตั้งอัตโนมัติ
        ├── libusb0.dll              <-- ตัวเชื่อมต่อ (Bridge)
        └── libusb0.sys              <-- Filter Driver ตัวจริง
```

## ⚠️ การแก้ปัญหาเบื้องต้น (Troubleshooting)
- **รันแล้ว Error / หาไฟเข้าไม่เจอ:** ให้ลองกดรันสคริปต์ใหม่ด้วยสิทธิ์ Admin (`Run as Administrator`) สักหนึ่งครั้ง เพื่อให้ตัวติดตั้งทำงานได้สมบูรณ์
- **เปิด WinpowerG2 ค้างไว้:** หากคุณติดตั้งโปรแกรม WinpowerG2 ตัวเต็มไว้ และเปิดโปรแกรมค้างอยู่ มันอาจจะแย่งการเชื่อมต่อกับสคริปต์ Python แนะนำให้ปิด Service ของ WinpowerG2 ก่อนใช้งานโมดูลนี้
